# Anime Player

Anime Player is a lightweight and powerful media player designed specifically for anime lovers. Built with **Electron.js**, it provides a smooth playback experience with GPU acceleration, customizable shortcuts, and an intuitive user interface.

## 🧐 Features

- 🎥 **Optimized Video Playback** - Smooth performance even on low-end devices.
- ⚡ **Fast Media Loading** - Direct file access for instant playback.
- 📂 **Multi-Format Support** - Supports MP4, MKV, AVI, and many more.
- 🎮 **Global Shortcuts** - Seamlessly control playback with keyboard commands.
- 🔄 **Auto-Resume Playback** - Pick up where you left off.
- 🌍 **Multi-Language Support** - Enjoy Anime Player in different languages.
- 🔄 **Auto-Update System** - Stay up to date with the latest features.
- 🔊 **Audio Controls** - Change tracks, adjust delay, and sync.
- 🖼️ **Video Effects & Rotation** - Rotate, zoom, and move videos easily.
- 🗑️ **File Management** - Quickly delete videos directly from the player.
- 🖥️ **Picture-in-Picture Mode** - Watch videos while multitasking.
- 📋 **Playlist & Queue Management** - Easily organize and navigate media.
- ⏲️ Sleep Timer - Automatically stop playback after a set time.

## 📥 Installation

### From Releases
1. Go to the [Releases](https://github.com/animeredits/anime-player/releases) page.
2. Download the latest version for your operating system:
   - **Windows:** `AnimePlayer-Setup.exe`
   - **macOS:** `AnimePlayer.dmg`
   - **Linux:** `AnimePlayer.AppImage`
3. Install and enjoy Anime Player!
